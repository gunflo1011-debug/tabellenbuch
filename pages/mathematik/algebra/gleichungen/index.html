Equations

An equation states that two mathematical expressions have the same value. Solving it means finding every value of the unknown that makes that statement true.

2x + 3 = 11
preserve equality on both sides
x = 4

START WITH THE IDEA

What does solving an equation mean?

Three ideas make nearly every algebraic solving method easier to understand.

01

Equality is a statement

The equals sign says that the expression on the left and the expression on the right represent the same value.

02

Solutions make it true

A solution is a value that satisfies the original equation. The collection of all such values is its solution set.

03

Transform, but preserve

We replace an equation by an equivalent one using operations that preserve exactly the same solutions.

CORE PRINCIPLE

Do the same valid operation to both sides.

Add or subtract the same quantity on both sides.
Multiply or divide both sides by the same non-zero quantity.
Simplify carefully and keep track of restrictions when operations may not be reversible.
Check the result in the original equation, especially after squaring, taking roots or clearing variable denominators.
